WWDC MCP · HELP CENTER

Get an Apple-guidance question unstuck.

WWDC MCP is operated by SMAT Designs (Scott Manthey). It is a free, public, read-only service that searches current Apple developer material — WWDC sessions, Apple documentation, the Human Interface Guidelines, Swift Evolution, and the App Store Review Guidelines — and returns source evidence to your AI client.

Check the service first

The service status endpoint is https://wwdc-mcp.smatdesigns.com/healthz. If it reports ok: true, the service is up and the problem is most likely in the connection or the question — the steps below will help us find which.

Public problems and resolved cases

Public support runs on GitHub: https://github.com/jabbertones-cloud/wwdc-mcp-server/issues. Search existing issues first — wrong or missing Apple results are often already tracked there, including an "Apple source drift" template for when an Apple page has changed. Never post API keys, bearer tokens, signing credentials, private source code, customer data, or Apple account information in a public issue.

Need private help?

Email jamonwidit@plushtrap.com. Please include:

  • Your MCP client (for example, ChatGPT) and whether you connect over HTTP or run the server locally (stdio).
  • The WWDC MCP version you used, if you run it locally.
  • What you asked: the tool name and query, and the source URL when you know it.
  • What you expected, what you got instead, and the output of the wwdc_ingest_status tool if a result looks stale or missing.

Do not send credentials, private signing keys, or Apple account details — support never needs them.

Common problems

"rate_limited" / HTTP 429. The public service limits how many tool calls one connection can make in a burst to keep it available for everyone. Wait for the time given in the response's Retry-After header and try again; discovery calls (listing tools) are not charged.

A result looks out of date. The index is rebuilt from Apple's public sources on a refresh cycle, not continuously. Ask the service itself with the wwdc_ingest_status tool — it reports when each source was last ingested — and include that output in your report.

Security issue. Use a private GitHub security advisory on the repository instead of a public issue.

What WWDC MCP cannot do

WWDC MCP cannot submit apps, upload builds, change App Store Connect state, or act on your Apple account — it is read-only by design. For App Store Connect release work, use the separate AiSCent product. WWDC MCP can still give you the guideline and session evidence to prepare.
