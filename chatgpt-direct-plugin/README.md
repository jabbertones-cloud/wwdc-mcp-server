# SMAT WWDC Direct — ChatGPT private plugin

The exact existing hosted endpoint is `https://wwdc-mcp.smatdesigns.com/mcp`.
This package does **not** require RemoteDesk or a new tunnel. It does not
provide any Apple-account write authority. The server is publicly accessible,
read-only, and contains 45 research tools.

Before marking this installed, connect the plugin in the ChatGPT Plugins UI and
run `wwdc_ingest_status`, `swift_app_audit`, and an App Store guideline query.
The package alone is not evidence that tools are installed in a chat.
