Connect AppDev Atlas

Start with the free hosted service in an MCP client that supports remote Streamable HTTP. No Node.js installation, local index, or Apple account is required for public read-only research.

1. Add the remote MCP URL

In your client's MCP settings, choose a remote HTTP MCP server and paste this endpoint. Connection steps differ by client.

https://wwdc-mcp.smatdesigns.com/mcp

If your client doesn't support remote Streamable HTTP, use the local installation below. The latest MCPB bundle is another option for compatible clients.

2. Ask a specific Apple development question

Use AppDev Atlas to check current Apple guidance for SwiftUI navigation.
Show the source links and say what still needs verification.

3. Verify that it actually used the tools

Look for the MCP tool call, a real Apple source URL, and any corpus-freshness caveats. If the agent answers without invoking AppDev Atlas, check the connection and client permissions rather than assuming the research was performed.

Prefer a local index?

Use the stdio server if you want to manage your own index and source updates. This path requires Node.js 22.14+, npm, network access for ingestion, and sufficient time and disk space for the selected corpus. It is not required for hosted use.

1. Clone and build

git clone https://github.com/jabbertones-cloud/wwdc-mcp-server.git
cd wwdc-mcp-server
npm ci
npm run build

2. Ingest the Apple sources you need

npm run ingest:wwdc -- --year 2026

For all supported core sources, run npm run ingest:all. Ingestion can take longer depending on connectivity and corpus size. Keyword search uses local SQLite FTS5; optional semantic reranking uses Hugging Face Transformers/ONNX and may download model files on first use. Ollama is not required.

3. Connect a local MCP client

For example, in Cursor's ~/.cursor/mcp.json:

{
  "mcpServers": {
    "wwdc": {
      "command": "node",
      "args": ["/absolute/path/to/wwdc-mcp-server/dist/index.js"]
    }
  }
}

Replace the path with the actual location of your checkout. For other clients and bundle install details, see the README or support guide.
