What it is

A local-first MCP server that runs on your Mac over stdio. It indexes Apple's developer material so your agent checks the source instead of guessing.

45
read-only tools — nothing mutates your Apple account or your code
2020–26
WWDC session years in the index, with full transcripts
Local
SQLite FTS5 keyword search plus optional Ollama semantic reranking; no paid APIs
MIT
open source; works with Codex, Claude, Cursor, Windsurf, and Zed
The prompt that matters most Audit this app against current Apple guidance before changing code.

Give that to your agent and it has to pull evidence — WWDC sessions, HIG entries, Swift Evolution proposals, review guidelines — before it recommends the work.

Key tools

Every tool is read-only. Retrieved content is tagged as evidence, not instructions.

swift_app_audit

Audit a Swift/SwiftUI/macOS/iOS app against WWDC sessions, HIG, tutorials, and Swift Evolution.

wwdc_search

Hybrid keyword + semantic search across sessions, docs, tutorials, HIG, and evolution proposals.

wwdc_transcript_search

Search inside session transcripts, not just titles and descriptions.

wwdc_session_deep_link

Generate a URL with ?time=SECONDS that jumps straight to the chapter in a session.

apple_api_deprecation

Check the deprecation status of an Apple API before your agent uses it.

apple_what_replaced

Find the current replacement for a deprecated Apple API.

apple_hig_search

Search the Human Interface Guidelines for platform behavior rules.

apple_swift_evolution_get

Pull a Swift Evolution proposal by id (e.g. SE-0428) with status and rationale.

appstore_guidelines_search

Search the App Store Review Guidelines before you archive a build.

Install

Requires Node.js 22.14 or newer. Takes about a minute.

1. Clone and build

git clone https://github.com/jabbertones-cloud/wwdc-mcp-server.git
cd wwdc-mcp-server
npm install
npm run build

2. Build the local index

npm run ingest:wwdc

Optional: npm run ingest:all adds tutorials, docs, HIG, and Swift Evolution. Optional: ollama pull nomic-embed-text enables semantic reranking; without Ollama it falls back to keyword search.

3. Connect your client

Cursor — ~/.cursor/mcp.json:

{
  "mcpServers": {
    "wwdc": {
      "command": "node",
      "args": ["/absolute/path/to/wwdc-mcp-server/dist/index.js"]
    }
  }
}

Claude Desktop — ~/Library/Application Support/Claude/claude_desktop_config.json:

{
  "mcpServers": {
    "wwdc": {
      "command": "node",
      "args": ["/absolute/path/to/wwdc-mcp-server/dist/index.js"],
      "env": {
        "OLLAMA_BASE": "http://127.0.0.1:11434",
        "OLLAMA_EMBED_MODEL": "nomic-embed-text"
      }
    }
  }
}

The README also covers VS Code, Windsurf, and Zed. For hosted use, connect directly to https://wwdc-mcp.smatdesigns.com/mcp.
