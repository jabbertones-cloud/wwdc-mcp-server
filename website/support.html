How to get help

AppDev Atlas is a read-only Apple developer intelligence service for coding agents and ChatGPT.

Developed independently by SMAT Designs; not affiliated with or endorsed by Apple or OpenAI.

Common tasks

  • Connect ChatGPT to https://wwdc-mcp.smatdesigns.com/mcp (public read-only, no auth)
  • Ask: check ingest status, then cite current Apple guidance for a SwiftUI topic
  • Local install and docs: github.com/jabbertones-cloud/wwdc-mcp-server

Public issues and agent support

Search AppDev Atlas support issues, or report a bug or request a feature. The public support README includes troubleshooting guidance and privacy rules.

Agents can search, read, draft and reply to issues through a separate GitHub connection authorized by the user. AppDev Atlas does not grant GitHub write permissions. Do not post private source code, credentials, or sensitive account information in public issues.

Contact

Email support@smatdesigns.com for connection issues, incorrect tool results, or privacy requests (privacy@smatdesigns.com).

Include: client name (ChatGPT/Cursor/etc.), approximate time of the request, tool name, and what you expected vs received. Do not send Apple API keys or private credentials.
