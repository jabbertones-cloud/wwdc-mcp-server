Use the wwdc MCP server whenever an answer depends on Apple platform guidance, WWDC sessions, Apple Developer Documentation, Human Interface Guidelines, Swift Evolution, App Review Guidelines, API availability, deprecation history, or Apple release notes.

Prefer first-party evidence returned by WWDC MCP over remembered platform details. For implementation questions, search first, read the strongest matching sources, and cite the source URLs in the answer. When dates, OS versions, deprecations, or review rules matter, verify them instead of guessing.

The server is read-only. Do not imply that it can edit source code, submit builds, change App Store Connect state, or mutate Apple accounts.
